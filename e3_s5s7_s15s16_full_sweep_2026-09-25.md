# S5-S7/S15-S16 full value-sweep, matching the A2/A6 pattern (2026-09-25)

Closes the disclosed limitation in the obligation/assurance-claim model paragraph
(`subsec:results-attacks`): "a further real value-sweep across mechanism-strength levels,
matching the pattern already used for A2/A6, remains open." The original real on-chain test
covered only the 7 obligation and 6 assurance hand-picked scenarios from
`e3_obligation_model.py`/`e3_assurance_claim_model.py`; this extends both to a full combinatorial
sweep of every real value the models define, as real, separately committed Fabric transactions
against the existing, unmodified `SubmitDecisionObligationV2`/`SubmitDecisionAssuranceV2`
chaincode entry points (v2.21/seq33) -- no chaincode changes.

## Method

`sweep_obligation_assurance.js` independently computes expected ground truth (mirroring
`oblCoveredV2`/`claimsFor` from `obligation_v2.go`/`assurance_a6.go`, the same relationship the
original 7+6 scenario check already used), then submits one real transaction per combination and
compares the observed class. `role=manager`, `amount=200000`, `sourceLimit=500000`,
`semBound=true`, `evAssuranceOK=true` are held fixed for every case so the observed class is a
pure function of the swept dimension alone (identity role mapping + amount within threshold means
class is `EXACT` when the swept condition holds, `REJECT` otherwise -- verified directly against
the chaincode source before running, not assumed).

**Obligation sweep** (S5 stripping / S6 weakening / S7 laundering): `obligation_profile` in
{notification, audit, dual_approval, combined} (4; `empty` excluded as a degenerate
always-covered case already tested by the original scenario matrix) x `mapped_mechanism` in
{none, notification, audit, dual_approval, combined} (5) x `obligation_discharged` in
{true, false} (2) x `enforcement_witness_verified` in {true, false} (2) = **80 real cases**.

**Assurance sweep** (S15 honest-insufficient / S16 fake-upgrade): `claimed_tier` in
{classical, hybrid, pq} (3) x `verified_tier` in {classical, hybrid, pq, unverifiable} (4) x
`dest_requirement` in {ClassicalDecisionAuth, PQDecisionAuth} (2) = **24 real cases** (full
coverage of all 3 dimensions actually recorded on-chain, even though `assure_ok_v2`'s boolean
output only depends on `verified_tier`/`dest_requirement` by design -- every `claimed_tier` is
exercised against every possible over-claim/no-claim combination).

## Real bug found and fixed while building this

The first run reported 0/80 and 0/24 -- every case appeared to fail. Root cause: `peer chaincode
invoke`'s human-readable "payload" line is written to **stderr**, not stdout, but the script
originally used `execFileSync` (which returns only stdout on success). All 104 transactions had
in fact committed correctly on-chain; the script simply could not read back their real results.
Fixed by switching to `spawnSync` and concatenating stdout+stderr before parsing. Re-run clean
after the fix; the original mis-read batch's decisionIDs are distinct (timestamp-prefixed) and
were left on the ledger as harmless extra real transactions, not overwritten or hidden.

## Results

**Obligation: 80/80 correct** (95% Clopper-Pearson upper bound on the true failure rate:
$1-0.05^{1/80}=3.68\%$, down from $34.82\%$ at the original n=7).

**Assurance: 24/24 correct** (95% upper bound $1-0.05^{1/24}=11.73\%$, down from $39.30\%$ at
the original n=6).

**Combined: 104/104 correct** (95% upper bound $1-0.05^{1/104}=2.84\%$).

Zero mismatches across the entire sweep, including every boundary case (mechanism strength
exactly equal to required, one level below, one level above; every claimed/verified tier
combination including the `unverifiable` sentinel).

## Interpretation

This closes the last disclosed real-experiment gap for S5-S7/S15-S16: the discrimination the
extended obligation/assurance models provide (stripping vs weakening vs laundering; honest
insufficiency vs fake upgrade) now has full real, on-chain, combinatorial coverage matching the
rigor already established for A2 and A6, not just the original hand-picked scenario matrix.
