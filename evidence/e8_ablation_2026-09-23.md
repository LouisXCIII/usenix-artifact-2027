## A10: TAC/context binding (real, extends S19)

`~/pqc-hardhat/experiments/portability/a10_tac_binding_ablation.js`. Reuses
S19's real TAC construction (real Keccak-256 hashing, real ECDSA signature
over a real on-chain decision), but with the field-binding check removed
from verification -- the ablated verifier checks only that the issuer's
signature is valid over the certificate's *own* digest, not that the
presented context matches what was originally certified. Result: **all 5
substitution attempts that S19 correctly rejected now succeed (5/5)**,
confirming field-binding, not signature validity alone, is what defends
against TAC substitution. Raw output:
`evidence/a10_tac_binding_ablation_result_2026-09-23.json`.

## A11: multi-hop preservation (real, reuses X5a)

Not a new experiment: X5a (`evidence/x5a_two_hop_counterexample_2026-09-21.json`,
already real) is itself exactly this ablation. Its `boolean_path` field is
pairwise-local acceptance (each hop checked independently, no composed
end-to-end state) -- the A11-ablated configuration -- and returns
`SAFE`. Its `trustless_path`/`trustless_path_v6` fields are the full,
composed, real light-client-and-proof-verified result -- the reference
(A0-equivalent) configuration -- and both return `REJECT` (the real second
hop has `semBound=false`, detected only by the composed check). This is a
real, on-chain (block `0x606cb`) demonstration that removing multi-hop
preservation lets an unsafe end-to-end transfer through that the full
mechanism catches.

## Honest scope notes

- A1–A9's FAR values come from the SAME 2,000-case corpus as E1; they are
  not independently re-generated, so they share E1's known limitations
  (synthetic/stratified sampling, not a targeted red-team suite; the
  role/amount fragment is the one with an on-chain analog, the
  action/resource/context families are formal-only).
- A10 is a standalone module ablation (same caveat as S19 itself): it shows
  the mechanism's necessity in isolation, not an ablation of an integrated
  production system.
- A11 reuses n=1 real evidence (X5a), consistent with the project's existing
  n=2-hop-only limitation, tracked separately as the E9 gap.
